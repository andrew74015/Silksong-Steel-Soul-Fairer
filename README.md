# Silksong New Game Plus

A New Game Plus save for Hollow Knight: Silksong. The world starts over from the
beginning and Hornet keeps her equipment.

Built on game version 1.0.30000. PC and Steam, profile slot 4, Classic mode. This
is a save file, not a mod. No code runs and nothing is injected.

## Installing

Close the game, back up your own save, then copy `user4.dat` into

    %USERPROFILE%\AppData\LocalLow\Team Cherry\Hollow Knight Silksong\<your-id>\

If the game is still running when you copy, Steam Cloud can put your old file back
when you quit.

## Detail

`CHANGES.md` lists what the save carries over and what it resets.
